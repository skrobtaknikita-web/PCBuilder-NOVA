

\# PCBuilder NOVA



PCBuilder NOVA — веб-приложение для подбора комплектующих и создания персональных конфигураций компьютеров.



Проект разработан в рамках курсовой работы по специальности «Информационные системы».



\## Технологии



\- PHP 8.3

\- Laravel 12

\- Laravel Sanctum 4

\- MySQL

\- REST API

\- Composer

\- PHPUnit 11

\- Git и GitHub



\## Основные возможности



\### Каталог комплектующих



\- Просмотр комплектующих компьютера

\- Поиск по названию и производителю

\- Фильтрация по категориям и стоимости

\- Сортировка по цене, названию, дате и остаткам

\- Отображение наличия и характеристик

\- Постраничная загрузка товаров



\### Конфигуратор компьютера



\- Создание персональных сборок

\- Добавление и удаление комплектующих

\- Редактирование и сохранение конфигураций

\- Автоматический расчёт стоимости

\- Проверка наличия комплектующих

\- Сохранение данных в MySQL



\### Проверка совместимости



Система автоматически проверяет:



\- Соответствие сокета процессора и материнской платы

\- Совместимость типа оперативной памяти

\- Достаточность мощности блока питания

\- Запас мощности блока питания 20%

\- Соответствие длины видеокарты корпусу

\- Доступность выбранных комплектующих



При расчёте энергопотребления учитывается количество компонентов.



\### Готовые сборки



В приложении предусмотрены шаблоны:



\- Офисный компьютер

\- Игровой компьютер

\- Мощный игровой компьютер

\- Рабочая станция



Рекомендации формируются на основе доступных комплектующих каталога. Подбор не гарантирует попадание в бюджет или полную совместимость всех компонентов.



\### Авторизация



\- Регистрация пользователей

\- Авторизация через Laravel Sanctum

\- Выход из аккаунта

\- Завершение всех активных сессий

\- Разграничение прав пользователей и администраторов



\### Администрирование



\- Управление каталогом комплектующих

\- Управление категориями

\- Управление правилами совместимости

\- Просмотр статистики

\- Контроль складских остатков

\- Просмотр количества пользователей и сборок



\## Установка и запуск



\### Требования



\- PHP 8.3 или новее в пределах поддерживаемой версии

\- Composer

\- MySQL

\- Laragon или аналогичное локальное окружение



\### 1. Клонирование репозитория



```bash

git clone https://github.com/skrobtaknikita-web/PCBuilder-NOVA.git

cd PCBuilder-NOVA

```



\### 2. Установка зависимостей



```bash

composer install

```



\### 3. Настройка окружения



Создайте файл `.env` на основе `.env.example`.



Для Windows:



```cmd

copy .env.example .env

```



Сгенерируйте ключ приложения:



```bash

php artisan key:generate

```



\### 4. Настройка базы данных



Создайте базу MySQL и укажите параметры подключения в `.env`:



```dotenv

DB\_CONNECTION=mysql

DB\_HOST=127.0.0.1

DB\_PORT=3306

DB\_DATABASE=pc\_configurator

DB\_USERNAME=root

DB\_PASSWORD=

```



При необходимости измените имя базы, пользователя и пароль.



\### 5. Миграции



```bash

php artisan migrate

```



Для заполнения каталога тестовыми данными при наличии соответствующих сидеров:



```bash

php artisan db:seed

```



\### 6. Запуск сервера



```bash

php artisan serve

```



Адрес приложения:



http://127.0.0.1:8000



\## Основные API-маршруты



\### Публичные



| Метод | Маршрут | Назначение |

|---|---|---|

| GET | /api/health | Проверка сервера |

| POST | /api/register | Регистрация |

| POST | /api/login | Авторизация |

| GET | /api/components | Каталог |

| GET | /api/components/{component} | Информация о товаре |

| GET | /api/categories | Категории |

| GET | /api/system/info | Информация о системе |

| GET | /api/ready-builds | Список готовых сборок |

| GET | /api/ready-builds/{slug} | Рекомендуемая сборка |

| POST | /api/ai/advise | Помощник по подбору |



\### Для авторизованных пользователей



| Метод | Маршрут | Назначение |

|---|---|---|

| GET | /api/user | Текущий пользователь |

| POST | /api/logout | Выход |

| POST | /api/logout-all | Выход со всех устройств |

| GET | /api/configurations | Мои сборки |

| POST | /api/configurations | Создание сборки |

| GET | /api/configurations/{configuration} | Просмотр сборки |

| PUT/PATCH | /api/configurations/{configuration} | Редактирование |

| DELETE | /api/configurations/{configuration} | Удаление |



\### Для администратора



\- Управление комплектующими через /api/components

\- Управление категориями через /api/categories

\- Управление правилами через /api/compatibility-rules

\- GET /api/reports/summary — статистика системы



\## Тестирование



Для запуска всех тестов:



```bash

php artisan test

```



Для просмотра маршрутов:



```bash

php artisan route:list --path=api

```



Тесты охватывают регистрацию, авторизацию, каталог, конфигуратор, проверки совместимости и административные функции.



\## Структура проекта



\- `app/Http/Controllers/Api` — контроллеры API

\- `app/Http/Requests` — проверка входящих данных

\- `app/Http/Resources` — формирование JSON-ответов

\- `app/Models` — модели базы данных

\- `app/Services` — бизнес-логика

\- `database/migrations` — миграции

\- `database/seeders` — заполнение базы

\- `routes/api.php` — маршруты API

\- `tests/Feature` — функциональные тесты
