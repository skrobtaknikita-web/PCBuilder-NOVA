# PCBuilder NOVA 5.0 — инструкция для Windows/Laragon

## Первый запуск
1. Установите Laragon (PHP 8.3+, MySQL) и Composer, нажмите Start All.
2. Распакуйте архив в новую папку, **не заменяя работающий проект без резервной копии**.
3. Скопируйте `.env.example` в `.env` (скрипт START_NOVA_WINDOWS.bat сделает это, если файла нет).
4. В `.env` установите `DB_CONNECTION=mysql`, `DB_DATABASE=pc_configurator`, `DB_USERNAME=root`, `DB_PASSWORD=`. Создайте базу `pc_configurator` заранее.
5. Дважды щёлкните `START_NOVA_WINDOWS.bat`, согласитесь на импорт демо-каталога.
6. Откройте http://127.0.0.1:5500 . API: http://127.0.0.1:8000/api/health .

Если скрипт не нашёл PHP, запустите команды вручную в Laragon Terminal:
```
composer install
copy .env.example .env
php artisan key:generate
php artisan migrate
php artisan db:seed
php artisan serve
```
Во втором терминале из `client`: `php -S 127.0.0.1:5500`.

## Каталог
В каталоге 1 860 учебных позиций, включая известные названия моделей и автоматически созданные демонстрационные варианты. **Это не импорт реальных предложений магазинов.** Цены и остатки условные, некоторые характеристики требуют проверки у производителя. Повторное `db:seed` обновляет записи по категории и названию. Демо-аккаунты используют пароль `Password123!` — только для локального тестирования.

## ИИ
По умолчанию действует локальный справочный помощник. Для облачного ИИ установите серверный `OPENAI_API_KEY` в `.env`, затем `php artisan config:clear`. Никогда не размещайте ключ в `client/app.js`.

## Важные ограничения
Базовая совместимость проверяет сокет, RAM, длину GPU и мощность БП. Она не гарантирует поддержку BIOS, размеров радиатора, питания GPU и точность реального энергопотребления. Не выполняйте `migrate:fresh` на существующей базе. Перед обновлением сделайте резервную копию базы и `.env`.
