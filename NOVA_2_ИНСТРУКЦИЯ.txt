PCBuilder NOVA 2.0 — обновление существующего проекта

1. СДЕЛАЙТЕ РЕЗЕРВНУЮ КОПИЮ текущей папки pc-configurator и базы MySQL.
2. Остановите оба сервера (Ctrl+C в каждом терминале).
3. Распакуйте архив в отдельную папку. Скопируйте из неё client/, database/seeders/ в текущий проект, заменяя файлы. Остальной код Laravel совместим с исходным.
4. Не заменяйте .env и не удаляйте действующую базу данных.
5. В терминале Laragon: cd /d "C:\Users\hiki\Desktop\pc-configurator"
6. Выполните: php artisan db:seed
7. Запустите Laravel: php artisan serve
8. Во втором терминале: cd /d "C:\Users\hiki\Desktop\pc-configurator\client"
9. Выполните: php -S 127.0.0.1:5500
10. Откройте http://127.0.0.1:5500

Каталог: 246 демонстрационных позиций, 9 категорий. Цены ориентировочные, не актуальные предложения магазинов. Данные построены для демонстрации работы конфигуратора. Существующие записи при db:seed не удаляются.

Примечание: проверка совместимости в браузере — предварительная; сервер проверяет основные правила при сохранении. Новые категории cooler/fan поддерживаются базой и каталогом, но серверная проверка совместимости для них пока не расширена.
