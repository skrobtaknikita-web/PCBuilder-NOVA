NOVA 14 — система реальных фотографий

ВНИМАНИЕ: Фотографии для всех 2371 товаров не собраны и не подтверждены.
В каталоге больше не отображаются случайные стоковые фотографии как изображения товаров.
Для каждой модели есть ссылка «Найти фото», открывающая поиск изображений точной модели.
Неподтвержденные изображения Wikimedia открываются отдельно, но не подменяют фотографию товара.

Как привязать проверенную фотографию:
1. Найдите точную модель и убедитесь, что изображение соответствует ей.
2. Проверьте право использования фотографии и условия лицензии.
3. В client/assets/verified-photos.json добавьте запись вида:
{
  "msi geforce rtx 4070 super gaming x slim": {
    "url": "https://example.com/permitted-exact-product-photo.jpg",
    "source": "https://example.com/photo-license-or-product-page"
  }
}
Ключ — бренд и название модели в нижнем регистре с пробелами вместо знаков пунктуации.
Пример URL является заглушкой; не использовать как рабочее изображение.

Замените папку client в вашем проекте, не копируйте серверные файлы.
