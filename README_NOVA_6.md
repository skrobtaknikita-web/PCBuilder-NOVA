# PCBuilder NOVA 6.0 — тесты, ИИ и большой учебный каталог

## Что добавлено
- 500 новых **явно помеченных NOVA DEMO** вариантов: всего 2360 позиций. Это не реальные SKU и не магазинные цены.
- Локальный помощник теперь отвечает через API даже без ключа; различает локальный и облачный режим.
- Облачный ИИ через OpenAI Responses API с контекстом выбранной сборки и до 8 совпадений из каталога. Ключ хранится только на сервере.
- 8 дополнительных автоматических тестов: валидация, локальный режим, облачный ответ, ошибка API, поиск по каталогу, пагинация и отсутствие дубликатов.

## Запуск Windows/Laragon
1. Сделайте резервную копию предыдущей папки проекта и MySQL.
2. Распакуйте ZIP. В папке проекта выполните `composer install`.
3. Если `.env` отсутствует: `copy .env.example .env` и `php artisan key:generate`.
4. В `.env` настройте MySQL: DB_CONNECTION=mysql, DB_DATABASE=pc_configurator, DB_USERNAME=root, DB_PASSWORD= (если пароль пуст).
5. Запустите MySQL в Laragon. Затем `php artisan migrate` и `php artisan db:seed`.
6. Запустите `php artisan serve`. Во втором терминале из `client`: `php -S 127.0.0.1:5500`.
7. Сайт: http://127.0.0.1:5500 . API: http://127.0.0.1:8000/api/health .

## Тесты
В Laragon Terminal из корня проекта: `php artisan test`.
Для SQLite in-memory тестов нужны расширения pdo_sqlite и sqlite3 в PHP. Тестовая БД отдельная и не затрагивает MySQL.

## Облачный ИИ
Добавьте `OPENAI_API_KEY=...` и `OPENAI_MODEL=gpt-4.1-mini` в `.env`; `php artisan config:clear`.
API может быть платным. Без ключа доступен ограниченный локальный помощник. Не публикуйте ключ в JavaScript.

## Ограничения
Тесты подготовлены, но для полного прогона требуется установленный Composer/vendor и SQLite. Синтаксические проверки не равны интеграционным тестам. Совместимость проверяется частично, реальные цены и FPS не подтверждены. Никогда не используйте `migrate:fresh` для существующей базы.
